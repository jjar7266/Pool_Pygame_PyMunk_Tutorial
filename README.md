# 🎱 Pool Game in Python — Pygame‑CE + PyMunk Tutorial
### *A modernized, fully‑commented follow‑along project inspired by CodingWithRuss*

---

## 📌 Overview

This project is a beginner‑friendly **Pool Game** built using **Python**, **Pygame‑CE**, and **PyMunk**.
It follows the *“Making a Pool Game in Python the Easy Way”* tutorial by **CodingWithRuss**, with updates and modernizations where needed since the original video is older.

The entire codebase will be written in a **teacher/student style**, with **clear explanations**, **friendly comments**, and **step‑by‑step logic** to help beginners understand how physics, collisions, and game loops work in a real project.

---

## 🧰 Tech Stack

- **Python 3.x**
- **Pygame‑CE** — windowing, rendering, input, game loop
- **PyMunk** — physics engine (collisions, impulses, friction)
- **uv** — fast virtual environment + dependency management

---

## 🚀 Getting Started

### 1. Create uv environment
```
uv venv
```

### 2. Activate it
```
.\.venv\Scripts\activate
```

### 3. Install dependencies
```
uv pip install pygame-ce
uv pip install pymunk
```
